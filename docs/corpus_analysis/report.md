## 5. 结论与建议

1. **设备名语法覆盖率**：823/944（87.2%）的唯一条目能抽出 ID+设备后缀；928/944（98.3%）至少能抽出一个目标（含命名设备/对象/系统）。
2. **KIR 核心覆盖率**：923/944（97.8%）能抽出“动作+目标”；把场所（现场/后台机/顺控主机等条件类检查）也算作目标时为 934/944（98.9%）。其余主要是残片、纯状态描述、纯目标描述或票面噪声。
3. **票面噪声**：21 条含疑似 OCR/录入噪声，11 条引号不平衡，0 条含 0kv。票面即真值的前提是票面文本必须是官方原文；若语料来自 OCR，需先做票面勘误或把噪声条目标记为不可判定。
4. **复杂结构**：67 条含多设备/多对象，5 条含“至…之间”，39 条含冒号分隔的屏柜/目标，311 条含字母编号。这些必须用短语切分 + 最近编号关联，不能只靠一条全局正则。
5. **状态转换**：63 条能抽出状态转换，目标状态分布见上表。状态转换条目的 KIR 核心覆盖率为 100.0%。

**建议**：

- 以“短语切分 + 中心词 + 最近编号”为设备语法主干，再补电压/间隔/修饰字段；不要退回单条整句正则。
- 对无 ID 的命名设备/对象（母线保护、软压板、接地线、系统）单独建类，不强行要求编号。
- 严格档只对 KIR 核心/明细做精确比较；非关键信息只用于对齐，不参与判定。
- 票面噪声必须单列：加载时对“残片/无动作无目标/引号不平衡/0kv/疑似噪声”告警，必要时标记为不可判定，而不是静默判失败。
- 下一步可用同一脚本把每条票的 KIR 草稿导出，人工抽查 50~100 条，确定“检查/验明”“由…转…”等族的必填字段。
